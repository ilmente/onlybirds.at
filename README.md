# onlybirds.at

Website of onlybirds, birdwatching excursions and guided tours in Austria and Italy
with nature guide Pietro Bellezza.

A single-page site in German and Italian (`/` and `/it`): current excursion, guided tours
with downloadable PDF programmes, a short portrait, a bird gallery and contact details.

Built on [Kirby CMS](https://getkirby.com) 5 and PHP 8.2+. The site is a single Kirby theme
in `site/plugins/onlybirds`; see its [README](site/plugins/onlybirds/README.md) for the details.
Content is edited in the Kirby Panel and is not part of this repository.

## Local setup

```bash
composer install
```

Then serve the folder with any PHP web server, for example `composer start`.
